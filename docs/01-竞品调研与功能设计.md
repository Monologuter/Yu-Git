# 驭Git 竞品调研与功能设计

> 调研时间：2026-08。覆盖：Fork / Tower / Sublime Merge / Sourcetree / GitKraken / GitHub Desktop / GitUp / GitButler / lazygit / magit / jujutsu / SourceGit / ugit，以及 Git×AI 趋势（GitKraken AI、Copilot、Cursor、Conductor、Claude Code 工作流）与中文社区（V2EX/知乎/掘金）真实态度。

## 一、调研核心结论

1. **市场格局**：口碑王是 Fork（原生、快、$59.99 买断、可无限试用）；Tower 因订阅制被持续反弹；Sublime Merge 更新停滞、用户群正在寻找出路；Sourcetree 靠免费+中文苟活但性能口碑崩坏；GitKraken 的 Electron 是公认软肋。
2. **中文社区真相**：主流是「IDE 内置 + CLI」，独立 GUI 是补充工具（看历史/拆 commit/解冲突时打开）。**「中文界面」没有强烈呼声，是加分项和传播点，不是购买理由**——不能作为唯一卖点。中文用户只接受免费或买断，对订阅极度反感。
3. **新对手预警**：**SourceGit**——开源免费、<2MB、原生编译、简繁中文，在 V2EX 热度快速上升。任何「免费中文 Git 客户端」的定位都会直接撞上它。腾讯 ugit 则因安装包臃肿、内存占用大被群嘲——国产客户端翻车样本。
4. **AI 现状**：AI commit message 已是 table stakes（Fork/Tower/GitKraken/JetBrains 全有）；Fork 2025-11 已接入 Claude Code 做分支级 review。但所有玩家都只是「传统 GUI + ✨ 按钮」。**没人做**：仓库级时间线 Undo、AI Commit Composer 级别的深度整合、worktree/并行 agent 管理、对话式 Git。GitButler 拿 a16z $17M 做「AI 时代版本控制」，证明这是资本认可的真赛道。
5. **AI 时代新痛点（我们的机会）**：并行 agent + worktree 已成主流实践（Claude Code 官方建议开 3–5 个 worktree）；AI 产出的 diff 审查耗时是人写的 4.6 倍（review 成为新瓶颈）；Claude Code 的 checkpoint 只限单 session、不覆盖 bash 改动——「仓库级时间线」存在明确空位。
6. **AI 功能必须回答的问题**：用户已有 Claude Code/Cursor 在做 git 操作，「为什么在 GUI 里用 AI」的答案只能是**强 GUI 场景**：可视化预览 AI 动作、一键撤销、逐 hunk 冲突解决、拆 commit、diff review、历史考古。

## 二、必备基础盘（table stakes，缺一项就被拿去和 Fork 比时出局）

- 可视化 commit graph（门面，视觉质量决定第一印象）
- hunk/行级部分暂存（GUI 相对 CLI 的最大价值，必须做到最顺）
- 内置冲突解决（付费转化场景）
- 可视化 interactive rebase（含自动 backup tag 安全网——Fork 被称赞的核心）
- stash、多 remote、repo manager（多仓库管理）、submodule/LFS/GPG（ugit 因缺 GPG 被点名）
- **变更实时检测**（FSEvents 增量刷新——Sourcetree 弃坑第一原因就是「改了文件 GUI 没反应」）
- 快、稳、原生（秒开、大仓库流畅、低内存）
- 平台中立：GitHub/GitLab/**Gitee/自建 GitLab/Coding** 全支持

## 三、精华借鉴清单（来源 → 采纳形态）

| 来源 | 功能 | 我们的采纳 |

## 四、糟粕规避清单（前车之鉴）

1. **纯客户端功能收订阅费**（Tower 2018 至今被鞭尸）→ 本地 Git 功能免费或买断；订阅只绑定有真实边际成本的 AI 云能力
2. **Electron/卡顿/大内存/大安装包**（GitKraken、ugit 242MB+ 被群嘲）→ 原生 + 轻量本身就是传播点
3. **变更检测不实时**（Sourcetree 头号弃坑原因）→ FSEvents 是生死线
4. **免费版阉割私有仓库**（GitKraken 恶感教科书）→ 免费线划在「个人本地全功能」
5. **平台锁定 / 不像 Mac 应用**（GitHub Desktop、GitKraken）→ 平台中立 + 严格遵守 macOS 习惯
6. **更新停滞**（Sublime Merge、GitUp 口碑烧掉的原因）→ 小步快跑，发布节奏即营销
7. **擅改用户 git 环境、不兼容 hooks/agent 生态**（Fork 重置「无效」配置导致第三方 AI hook 失效）→ 对 hooks/外部 agent 绝对开放
8. **用恶心人的方式区分免费付费**（Sublime Merge 试用锁暗色主题）→ 用能力分层，不用体验羞辱
9. **中文产品自嗨**（ugit）→ 中文是体验加分项，产品力才是根本

## 五、驭Git 差异化设计（我们自己的功能）

### ① 仓库时间线 + 无畏 Undo（信任基建，全场景护城河）
每次仓库级操作（GUI 内 + 检测到的外部/agent 改动）记入 operation log + 快照，可视时间线侧栏，全局 Cmd+Z。agent 会话期间自动打快照点（「Claude 第 N 轮改动」），一键回到任意轮次。**跨 session、跨工具、覆盖 bash 改动——补上 Claude Code /rewind 的全部空位**。综合 Tower Undo + GitUp snapshots + jj operation log，无人做全过。

### ② AI Commit Composer（AI 时代最痛的新需求）
一轮 vibe coding 产生一坨混杂改动 → AI 按语义提议拆成 N 个逻辑 commit（各附中文说明），用户拖拽 hunk 调整分组后一键提交；也可对已有 commit 串重组。比「AI commit message」高一个层级，message 生成只是它的附属品。

### ③ Worktree / 并行 Agent 管理面板
worktree 一等公民：一键从任务创建 worktree（自动命名分支）、卡片显示各 agent 会话状态/改动量、完成后引导 review → merge → 清理。「Git 客户端 + agent 编排」融合体无人在做（Conductor 只做编排不做 Git 客户端），且 Conductor 证明了 macOS 原生定位可行。

### ④ AI 冲突解决（中文，逐 hunk）
三向合并视图中每个冲突块：AI 建议 + 中文理由 + 置信度色标，可采纳/修改/拒绝；支持自定义解决偏好。GitKraken 验证过的形态，中文语境无人做。

### ⑤ 本地 diff 的 AI 审查 + 风险分级导航
提交前在 GUI 内 review：中文摘要 + 内联问题标注 + 一键修复；大 diff 按风险排序（鉴权/数据层置顶，格式化折叠）。行业共识「审查模型独立于生成模型」——正好回答「为什么不在 coding agent 里 review」。

### ⑥ 中文解释 + AI 归因
任意 commit/branch/diff/冲突右键「用中文解释」（结果缓存）；blame 叠加 AI/人类归因层（识别 Cursor trailer、Co-Authored-By 标记）——「这行是哪个 agent 哪轮对话写的」。

### ⑦ 透明命令 + 中文教学层
每个 GUI/AI 操作显示等价 git 命令与中文注解；AI 执行任何操作前先展示将运行的命令（可审计）。界面即中文 Git 教材，承接新手成长曲线。

### ⑧ 对话式 Git 操作（v3，后置）
「把最近三个 commit 摘到 release 分支」→ AI 生成操作计划 → 可视化预览 + 显示命令 → 确认执行 → 时间线可撤销。依赖 ①⑦ 的安全网和透明层先就位。

**AI 设计铁律（全线贯彻）**：所有 AI 动作可预览、可编辑、可撤销；BYOK（DeepSeek/通义/OpenAI/Anthropic/本地 Ollama）；敏感文件内容不出本机。

## 六、商业模式建议

- **本地 Git 全功能免费**（含私有仓库——对标 SourceGit 的免费 + 打 GitKraken 的痛点）
- **AI 能力**：BYOK 免费用；后续可选内置云服务走订阅（订阅只收有边际成本的东西——已被 Fork/Tower 验证的路线）
- 远期高级功能（团队/云同步）再考虑买断制 Pro，心理价位对标 Fork（国区 ¥200 上下一次性）
