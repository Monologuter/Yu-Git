# 驭Git（Yugit）产品需求文档（PRD）

**产品名**：驭Git（英文环境显示 Yugit）· **Bundle ID**：`com.chenya.yugit` · **项目目录**：`~/soft/MacOSApp/Yugit`

> 状态：需求阶段，随讨论迭代。竞品调研依据见 `01-竞品调研与功能设计.md`。

## 1. 产品定位

**为 AI 编程时代而生的 macOS 原生 Git 客户端，中文为默认体验。**

一句话故事（Slogan）：**「AI 帮你写代码，驭Git 帮你驾驭它」**

四大支柱（均为核心卖点，分版本落地）：

1. **无畏 Undo**——仓库时间线，任何操作（含 agent 改动）可回溯可撤销
2. **AI Commit Composer**——混杂改动按语义拆成干净提交
3. **并行 Agent 指挥**——worktree/agent 会话的创建、监控、review、合并一条龙
4. **理解与审查**——AI 逐 hunk 解冲突、提交前审查、中文解释一切

与竞品的相对位置：

- 对 Fork/Tower：它们是「传统 GUI + ✨ AI 按钮」，我们从架构上围绕 AI 工作流设计
- 对 SourceGit（免费中文原生）：功能面对齐，靠 AI 深度和体验拉开
- 对 Conductor/GitButler：它们做 agent 编排或新范式，我们立足「完整 Git 客户端」这个用户已有心智的品类去融合 AI 能力

## 2. 目标用户

| 优先级 | 画像 | 核心诉求 |
|---|---|---|
| P0 | 重度使用 Claude Code/Cursor 的中文开发者（含开发者本人） | 管住 AI 产出：审查、拆提交、回滚、并行会话 |
| P1 | 用腻 Sourcetree/嫌 Fork 英文的普通中文开发者 | 快、稳、免费、中文、看历史/拆 commit/解冲突顺手 |
| P2 | Git 新手/学生 | 不怕搞坏（Undo）、看得懂（中文解释、透明命令） |

## 3. 功能需求（分版本）

### v0.1–0.3 内部 Alpha——「能自用的基础盘」
竞品及格线（详见 01 文档第二节）：打开/克隆仓库、实时状态（FSEvents）、hunk/行级暂存、提交/amend、分支增删切合、stash、fetch/pull/push（凭据透传）、commit graph 历史、字符级 diff、即时搜索、submodule/LFS/GPG 兼容、多仓库管理。
验收基调：开发者本人日常工作零终端；5 万 commit 仓库流畅。

### v0.5 公开 Beta——「第一个传播点」
- **仓库时间线 + 无畏 Undo**（支柱 1）：operation log + 快照、时间线侧栏、全局 Cmd+Z、外部/agent 改动自动快照点
- **Command Palette + 透明命令**：Cmd+K、每个操作显示等价 git 命令 + 中文注解
- **AI 基础能力（BYOK）**：AI commit message、中文解释 commit/diff/branch（低成本、高感知）
- 可视化 interactive rebase（自动 backup tag）+ Quick Actions

### v1.0 正式发布——「主打故事完整」
- **AI Commit Composer**（支柱 2）：AI 分析工作区/commit 串 → 提议语义分组 → 拖拽调整 → 一键提交
- **AI 逐 hunk 解冲突**（支柱 4）：建议 + 中文理由 + 置信度，可采纳/修改/拒绝
- **本地 diff AI 审查**（支柱 4）：提交前中文摘要 + 内联标注 + 风险分级导航
- 内置三向合并编辑器

### v1.5–2.0——「AI 指挥中心」
- **Worktree/并行 Agent 面板**（支柱 3）：一键建 worktree、agent 会话状态卡片、review→merge→清理流水线、Claude Code `--worktree` 约定集成
- **AI 归因 blame**：AI/人类改动分层（Cursor trailer、Co-Authored-By 识别）
- 平台集成：GitHub/GitLab/**Gitee/自建 GitLab** 的 PR/MR 管理
- 教学模式完善：危险操作预警、新手引导路径

### 远期
- 对话式 Git 操作（自然语言 → 操作计划 → 预览确认 → 可撤销执行）
- 内置 AI 云服务（开箱即用，订阅制）

## 4. AI 设计铁律（全线贯彻）

1. 所有 AI 动作**可预览、可编辑、可撤销**（时间线是安全网）
2. AI 执行操作前展示等价 git 命令（可审计）
3. BYOK：DeepSeek/通义/OpenAI/Anthropic/本地 Ollama；Key 存 Keychain
4. 隐私：代码默认不出本机；`.env`/credential 类敏感文件内容永不进 prompt；发送前显示上下文体积
5. AI 失败不阻塞：所有 AI 功能都有非 AI 降级路径

## 5. 非功能需求

| 维度 | 指标 |
|---|---|
| 性能 | 冷启动 < 1s；5 万 commit 仓库历史首屏 < 500ms、滚动 60fps；内存 < 500MB；安装包 < 30MB |
| 实时性 | 外部改动（终端/agent/IDE）≤ 500ms 反映到 UI |
| 稳定 | 不损坏用户仓库是底线；hunk 暂存/历史编辑全部有自动备份 |
| 开放 | 不擅改用户 git 配置；hooks/外部工具/agent 生态完全兼容 |
| 平台 | macOS 14+，Apple Silicon 优先；严格遵守 macOS 交互习惯 |
| 本地化 | 中文为第一语言（非翻译腔），英文界面同步提供；Git 术语保留英文 + 中文注解 |

## 6. 商业模式

- 本地 Git 全功能**永久免费，含私有仓库**（打 GitKraken 痛点、对齐 SourceGit）
- AI 能力 BYOK 免费用；远期内置云服务走订阅（订阅只收有边际成本的东西）
- 远期团队/云功能考虑买断 Pro，国区心理价位 ¥200 上下
- 绝不做：基础功能收订阅、试用羞辱（锁主题/水印）、免费版阉割私有仓库

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 工程量大（Git 客户端是出名深坑） | 严格按版本推进，v0.x 只做基础盘；技术风险清单见批准的实现计划 |
| Fork/Tower 跟进 AI | 它们受制于「传统 GUI 补丁式 AI」，我们的时间线/Composer/agent 面板需要架构级支持，跟进成本高 |
| SourceGit 免费+中文抢底盘 | 基础功能对齐即可，不在「免费中文」维度纠缠，差异化在 AI 工作流 |
| 单人开发节奏 | 小步快跑、公开 roadmap（Sublime Merge 停更教训）；社区沟通态度（Fork 教训） |
| AI 成本/合规 | BYOK 起步规避服务端成本与合规；内置服务后置 |
